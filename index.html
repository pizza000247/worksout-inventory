⑤ 스캔 기록 확인 · 중간 삭제

현재 선택한 로케이션의 기록만 표시합니다. CSV 저장에는 모든 로케이션 기록이 포함됩니다. 스캔 기록마다 품명·품번·색상·사이즈를 표시합니다. 현재 로케이션 미등록, 다른 로케이션 등록도 구분합니다. 일반 스캔은 1건씩 삭제하고, 대량 입력은 묶음 전체를 한 번에 삭제할 수 있습니다. 같은 바코드를 여러 번 찍었어도 선택한 1건만 지워집니다. 삭제를 누른 뒤 화면 안의 삭제 확정을 누르면 수량과 CSV 원본도 자동 반영됩니다. (아이폰 팝업 확인창을 사용하지 않습니다.)

⑥ 저장 및 복구

중간 기록을 삭제하면 내보내기 CSV에도 해당 상품 스캔이 제외되며, 필요한 로케이션 코드는 남은 상품 스캔 순서에 따라 다시 자동 삽입됩니다. 스캔 원본 CSV는 스캔일시/스캔로그 2열로 저장되며, 첫 상품 앞에 로케이션을 자동 추가합니다. 붙여넣기용 CSV는 한 열만 저장됩니다. 스캔 기록은 현재 브라우저에 임시 저장됩니다. 다른 기기나 브라우저로 자동 동기화되지 않으므로 CSV 또는 JSON 백업을 자주 저장하세요.
